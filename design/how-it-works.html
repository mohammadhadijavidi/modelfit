How ModelFit answers "can my Mac run this?"

Everything happens on your Mac, from the file header alone. No weights are loaded, nothing is uploaded.

Your model

.gguf file or split parts
.safetensors file or shards
MLX or Hugging Face folder with config.json

Drop it on the window, use File > Open, or press Space in Finder.

→

Header reader

GGUF: magic, version, metadata key-values, tensor infos.
safetensors: 8-byte length plus JSON header.

Big arrays (vocab, merges) are skipped by seeking. A few MB read, even for 70 GB models.

→

Model facts

Parameters from tensor shapes, exact bytes per tensor type (Q4_K, BF16, MLX 4-bit), layers, KV heads, head dimension, context length, vocabulary.

→

Memory estimate

weights   KV cache   overhead

KV = 2 × layers × ctx × kv_heads × head_dim × bytes

→

Verdict per context

2K, 8K, 32K and 128K tokens, capped at the model's maximum, with F16, Q8_0 or Q4_0 KV cache.
